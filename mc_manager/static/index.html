Recovery monitor

        

        
        

          
          
          
          
        

        
        
        
Stops through this panel, Discord controls, or the panel console are treated as intentional. Pause monitoring before stopping a server directly in a terminal. Unreachable hosts are never treated as confirmed server crashes.

        
After an outage, recovery waits for the host to return and for 60 seconds of confirmed line power. The host must power on automatically or be switched on; this cannot turn on an unpowered machine.

Create a release

              

                
                
                
                
                
                
              

              
              
              
              
Each file needs a relative path, HTTPS url, sha256, and byte size. Use [] for vanilla. Include only files intended for players.

              
File entry example
[{"path":"mods/example.jar","url":"https://downloads.example.net/example.jar","sha256":"<64 lowercase hex characters>","size":12345}]

              
Releases are saved permanently. Use a new version for changes. Saving does not publish or verify remote downloads.
